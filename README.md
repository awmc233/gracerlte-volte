# gracerlte-volte
VoLTE/IMS support for the Samsung Galaxy Note FE (gracerlte, Exynos 8890) on LineageOS 20 (Android 13). Ships a patched PhhIms build, a TWRP flashable zip, an adb installer, and a complete write-up of every fix — from IMS registration and RIL permissions to audio routing and carrier SDP quirks.
